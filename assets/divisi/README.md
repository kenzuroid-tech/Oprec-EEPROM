# Assets Divisi

Simpan file logo untuk setiap divisi di folder ini. Format logo yang didukung adalah PNG, JPG, JPEG, SVG, dll.

## Nama File Rekomendasi:
- `krai.png` (Logo KRAI / Aburobonema)
- `krsbi.png` (Logo KRSBI / Aroc-PL)
- `krsri.png` (Logo KRSRI / Robosarema)

*Catatan: Jika menggunakan format/nama lain (seperti `.svg` atau `.jpg`), silakan sesuaikan nama file di `index.html`.*
